# ALOK KUMAR SINGH — Black & Gold Creative Portfolio

A responsive five-page portfolio website with a premium black-and-gold theme.

Pages: Home, Work, Services, About, Contact.

## Preview
Open `index.html` in a browser.

## Personalize your portfolio
- Replace the sample images in `assets/` with your own work (keep the filenames or update the HTML).
- In `work.html`, replace the three video showcase placeholders with your own YouTube/Vimeo embeds or HTML video players.
- Review the education wording and portfolio descriptions before publishing so every claim accurately reflects your background and experience.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `YOUR-GITHUB-USERNAME.github.io` (replace the placeholder with your exact GitHub username).
2. Extract this ZIP on your device.
3. Upload the contents of this folder — `index.html`, the other HTML files, `styles.css`, `script.js`, and the `assets` folder — to the repository root. Do not upload the ZIP as a single file.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then save.
7. After GitHub finishes publishing, your free site address will be `https://YOUR-GITHUB-USERNAME.github.io/`.

A new deployment can take several minutes. GitHub Pages serves static HTML/CSS/JavaScript sites. The repository must be public for GitHub Free Pages hosting.
